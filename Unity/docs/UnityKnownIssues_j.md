# Unity Test - 既知の問題（Known Issues）

## 注意事項

このプロジェクトでは、利用者に影響を及ぼす可能性のある主なバグや問題点をできる限り記録・管理するよう努めています。  
より詳細かつ最新の情報については、UnityのGitHubリポジトリでご確認いただけます。

## 既知の問題

- **no-return関数（戻り値のない関数）の組み込み検証がない**  

- **Printf形式のフォーマットに対するサポートが不完全**  

- **可変長引数（VarArgs）へのサポートが不完全**
